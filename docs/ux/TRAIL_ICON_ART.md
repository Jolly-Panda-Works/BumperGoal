# Illustrated trail shop icons

Generated with built-in image_gen, one call per trail. Original alpha PNGs: `art-source/masters/trail-icons/`. Runtime transparent WebP icons: `apps/web/public/assets/trails/` (160 × 160). Re-export with `node tools/export-trail-icons.mjs`.

The shared TrailPreview component uses the same artwork in Shop, Locker and purchase confirmation. These are display changes only: prices, ownership and equipped selections remain intact.

The in-game trail buffer now begins at the exact current disc center. Disc sprites remain above the trail graphics; samples continue backward through the actual movement path, with speed-dependent length and taper. Idle/teleport clearing remains unchanged.
