# راهنمای افزودن آیتم جدید به فروشگاه FlickKick

این راهنما توضیح می‌دهد چطور در هر بخش فروشگاه (تیم‌ها، توپ‌ها، آواتارها، بسته‌های سکه و الماس) آیتم تازه اضافه کنید.
برای هیچ‌کدام لازم نیست کد بنویسید: هر آیتم فقط **یک ورودی در فایل کاتالوگ**، **یک تصویر** و **اسم فارسی، انگلیسی و عربی**
لازم دارد. بعد یک دستور، تصویر را برای بازی آماده می‌کند.

---

## ۱. نقشهٔ فایل‌ها

| چه چیزی                                             | کجا                                                                |
| --------------------------------------------------- | ------------------------------------------------------------------ |
| کاتالوگ فروشگاه (همهٔ آیتم‌ها، قیمت‌ها، رنگ‌ها)     | `packages/config/data/cosmetics.json`                              |
| اسم آیتم‌ها به انگلیسی و فارسی                      | `apps/web/src/i18n/en.json`، `fa.json` و `ar.json`                 |
| تصویر مهرهٔ تیم‌های FlickKick، توپ، آواتار، بسته‌ها | `art-source/masters/`                                              |
| تصویر مهرهٔ تیم‌های ملی و باشگاهی                   | `art-source/country-club-discs/`                                   |
| بافت تخت توپ (برای انیمیشن غلت خوردن)               | `art-source/ball-textures/`                                        |
| اسکریپت آماده‌سازی تصاویر                           | `tools/export-art.mjs` (با `pnpm art:export`)                      |
| کپی تنظیمات برای سرور                               | `server/nakama/gamedata/` (با `pnpm sync:gamedata`)                |
| کلید روشن/خاموش تیم‌های باشگاهی                     | `packages/config/data/economy.json` ← `features.clubTeams.enabled` |

> پوشهٔ `art-source` با **Git LFS** در گیت است. روی هر سیستم یک بار `git lfs install` بزنید، وگرنه به جای تصاویر فقط
> فایل‌های کوچک اشاره‌گر می‌گیرید.

---

## ۲. قدم‌های مشترک برای هر آیتم

۱. تصویر را با نام درست در پوشهٔ درست بگذارید (جدول هر بخش در ادامه).

۲. یک ورودی به بخش مربوط در `packages/config/data/cosmetics.json` اضافه کنید.

۳. اسم آیتم را در **هر دو** فایل ترجمه اضافه کنید (کلید = `id` آیتم).

۴. تصاویر را برای بازی آماده کنید:

```bash
pnpm art:export
```

۵. تنظیمات را برای سرور کپی کنید (بدون این، تست‌ها خطا می‌دهند و سرور آیتم را نمی‌شناسد):

```bash
pnpm sync:gamedata
```

۶. بازی را اجرا کنید و آیتم را در فروشگاه و «کمد» (Locker) ببینید:

```bash
pnpm dev
```

۷. قبل از کامیت همهٔ بررسی‌ها را اجرا کنید:

```bash
pnpm check
```

### قانون‌های `id`

- فقط حروف کوچک انگلیسی، عدد و `_` (مثلاً `club_tehran_red`).
- هر `id` یکتاست و **بعد از انتشار عوضش نکنید**: پروفایل بازیکنان با همین `id` ذخیره می‌شود.
- پیشوند هر بخش ثابت است: `team_` یا `nation_` یا `club_` برای تیم‌ها، `ball_` برای توپ، `avatar_` برای آواتار.

### قیمت (`price`)

| مقدار              | معنی                                                           |
| ------------------ | -------------------------------------------------------------- |
| `null`             | رایگان: همه از اول دارند و همین الان در Locker قابل انتخاب است |
| `{ "coins": 500 }` | ۵۰۰ سکه                                                        |
| `{ "gems": 20 }`   | ۲۰ الماس                                                       |

> خرید و مالکیت در محیط محلی فعال است و موجودی همین دستگاه را مصرف می‌کند. این مالکیت به سرور منتقل نمی‌شود؛ خرید سروری و پرداخت واقعی هنوز فعال نیستند. کمد فقط آیتم‌های موجود را نمایش می‌دهد.

`"default": true` یعنی آیتم پیش‌فرض بازیکنان تازه. در هر بخش فقط **یک** آیتم پیش‌فرض باشد.

## ۳. تیم‌ها (مهره‌ها)

تب «تیم‌ها» سه زیربخش دارد. زیربخش با فیلد `group` تعیین می‌شود:

| `group`    | زیربخش در فروشگاه | پیشوند `id` | تصویر                                             |
| ---------- | ----------------- | ----------- | ------------------------------------------------- |
| `original` | تیم‌های FlickKick | `team_`     | `art-source/masters/fk_piece_disc_<id>.png`       |
| `nation`   | تیم‌های ملی       | `nation_`   | `art-source/country-club-discs/fk_disc_<نام>.png` |
| `club`     | باشگاه‌ها         | `club_`     | `art-source/country-club-discs/fk_disc_<نام>.png` |

برای تیم ملی و باشگاه، `<نام>` همان `id` بدون پیشوند است: `nation_iran` ← `fk_disc_iran.png`،
`club_tehran_red` ← `fk_disc_tehran_red.png`.

### مثال: افزودن تیم ملی کره جنوبی

**تصویر:** `art-source/country-club-discs/fk_disc_south_korea.png`

**کاتالوگ** (`cosmetics.json` ← داخل لیست `"teams"`):

```json
{
  "id": "nation_south_korea",
  "group": "nation",
  "primary": "#CD2E3A",
  "secondary": "#0047A0",
  "emblem": "art",
  "price": { "coins": 400 }
}
```

**ترجمه‌ها** (داخل بخش `"teams"`):

- `en.json`: `"nation_south_korea": "South Korea"`
- `fa.json`: `"nation_south_korea": "کره جنوبی"`

### فیلدهای تیم

| فیلد        | توضیح                                                                                                                                                             |
| ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `primary`   | رنگ اصلی تیم. در افکت‌ها (موج ضربه، هالهٔ کشیدن، پرتوهای گل) استفاده می‌شود. اگر دو تیمِ یک مسابقه رنگ اصلی یکسان داشته باشند، بازی خودکار تیم دوم را عوض می‌کند. |
| `secondary` | رنگ دوم، فقط برای مهرهٔ جایگزین وقتی تصویر نیست.                                                                                                                  |
| `emblem`    | برای تیم‌هایی که تصویر دارند `"art"` بگذارید.                                                                                                                     |

### مشخصات تصویر مهره

- مربع، حداقل ۱۰۲۴×۱۰۲۴ پیکسل، PNG با پس‌زمینهٔ **کاملاً شفاف**.
- مهره دقیقاً از بالا (بدون دیوارهٔ کناری و بدون بیضی شدن)، وسط تصویر، حدود ۹۰٪ عرض.
- بدون سایه روی زمین (سایه را بازی خودش می‌کشد).
- در اندازهٔ ۵۶ پیکسل هنوز خوانا باشد.
- اسکریپت حاشیهٔ شفاف را خودش می‌بُرد و تصویر را به ۱۱۲×۱۱۲ می‌رساند.

### تیم‌های باشگاهی و مجوز

نشان باشگاه‌های واقعی (رئال مادرید، پرسپولیس و…) علامت تجاری ثبت‌شده است. انتشار عمومی بازی با این نشان‌ها **بدون مجوز
باشگاه یا لیگ** ریسک حقوقی دارد و فروشگاه‌های اپ ممکن است بازی را رد کنند. همهٔ باشگاه‌ها با یک کلید خاموش می‌شوند:

```json
"clubTeams": { "enabled": false }
```

(در `packages/config/data/economy.json`؛ بعدش `pnpm sync:gamedata`.) با خاموش بودن این کلید، باشگاه‌ها هم از فروشگاه
حذف می‌شوند و هم سرور اجازهٔ انتخابشان را نمی‌دهد. راه بی‌خطر جایگزین: مهرهٔ «رنگ شهر» با نشان طراحی‌شدهٔ خودتان
(مثلاً «قرمزهای تهران»).

## ۴. توپ‌ها

هر توپ **دو تصویر** دارد:

| تصویر                                | کجا دیده می‌شود         | مسیر                                                           |
| ------------------------------------ | ----------------------- | -------------------------------------------------------------- |
| تصویر ثابت توپ                       | فروشگاه و Locker        | `art-source/masters/fk_piece_ball_<id>.png`                    |
| بافت تخت (Equirectangular، نسبت ۲:۱) | غلت خوردن توپ در مسابقه | `art-source/ball-textures/fk_ball_texture_<نام>_2048x1024.png` |

`<نام>` همان `id` بدون `ball_` است: `ball_fire` ← `fk_ball_texture_fire_2048x1024.png`.

**کاتالوگ** (داخل `"balls"`):

```json
{ "id": "ball_fire", "primary": "#FF6B1A", "secondary": "#7A1F00", "price": { "gems": 20 } }
```

**ترجمه‌ها** (داخل بخش `"balls"`): `"ball_fire": "Fire"` و `"ball_fire": "آتشین"`.

**بافت توپ:** تصویر تخت ۲۰۴۸×۱۰۲۴، بدون نور و سایه و براق‌شدگی، لبهٔ چپ و راست کاملاً به هم وصل. اسکریپت از آن ۲۴ فریم
غلت خوردن می‌سازد و نور را جدا رویش می‌گذارد. اگر بافت نباشد، توپ در مسابقه بدون غلت خوردن (تصویر ثابت) نمایش داده
می‌شود.

---

## ۵. آواتارها

**تصویر:** `art-source/masters/fk_avatar_<نام>.png`. `<نام>` همان `id` بدون `avatar_` است.
مربع، حداقل ۱۰۲۴×۱۰۲۴. اسکریپت آن را به ۲۵۶×۲۵۶ برش می‌دهد (از وسط)، پس صورت را وسط تصویر بگذارید.

**کاتالوگ** (داخل `"avatars"`):

```json
{ "id": "avatar_lion", "price": { "coins": 600 } }
```

**ترجمه‌ها** (داخل بخش `"avatars"`): `"avatar_lion": "Lion"` و `"avatar_lion": "شیر"`.

---

## ۶. بسته‌های سکه و الماس (تب «سکه و الماس»)

**تصویر:** `art-source/masters/fk_thumb_<id>.png` (مربع، پس‌زمینهٔ شفاف).

**کاتالوگ** (داخل `"currencyPacks"`):

```json
{ "id": "pack_gems_m", "grant": { "gems": 300 }, "priceLabel": "TEST $9.99" }
```

| فیلد         | توضیح                                                             |
| ------------ | ----------------------------------------------------------------- |
| `grant`      | چه چیزی به بازیکن داده می‌شود: `coins`، `gems` یا هر دو           |
| `priceLabel` | برچسب قیمت برای اتصال آتی پرداخت واقعی                            |
| `oneTime`    | `true` یعنی هر بازیکن فقط یک بار می‌تواند بخرد (مثل پیشنهاد شروع) |

**ترجمه‌ها** (داخل بخش `"packs"`): `"pack_gems_m": "Bag of gems"` و `"pack_gems_m": "کیسهٔ الماس"`.

> پرداخت واقعی خاموش است (`features.payments.enabled: false` در `economy.json`) و برچسب‌ها `TEST` دارند. پرداخت واقعی
> به اتصال درگاه پرداخت (بازار/مایکت/گوگل‌پلی) نیاز دارد و کار جداگانه‌ای است.

## ۷. ترتیب نمایش

آیتم‌ها به همان ترتیبی که در `cosmetics.json` آمده‌اند نمایش داده می‌شوند. برای جابه‌جایی، ورودی را در لیست جابه‌جا کنید.
زیربخش‌های تیم‌ها همیشه به ترتیب «تیم‌های FlickKick»، «تیم‌های ملی»، «باشگاه‌ها» هستند.

## ۸. چک‌لیست نهایی

- [ ] تصویر با نام دقیق در پوشهٔ درست است (حروف کوچک، `_` به جای فاصله).
- [ ] ورودی کاتالوگ `id` یکتا و پیشوند درست دارد.
- [ ] اسم در `en.json` **و** `fa.json` اضافه شده.
- [ ] `pnpm art:export` اجرا شد و هشدار `no art for …` نداد.
- [ ] `pnpm sync:gamedata` اجرا شد.
- [ ] آیتم در فروشگاه و Locker درست دیده می‌شود (فارسی و انگلیسی).
- [ ] `pnpm check` سبز است.
- [ ] تصویرهای جدید `art-source` و خروجی‌های `apps/web/public/assets` و `artManifest.json` هر دو کامیت شده‌اند.

## ۹. خطاهای رایج

| نشانه                                             | علت و راه‌حل                                                                                                       |
| ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| به جای تصویر یک دایرهٔ ساده دیده می‌شود           | تصویر پیدا نشد. پیام `no art for …` در خروجی `pnpm art:export` مسیر مورد انتظار را می‌گوید؛ نام فایل را درست کنید. |
| به جای اسم، متنی مثل `teams.nation_x` دیده می‌شود | اسم در فایل ترجمه نیست یا کلیدش با `id` فرق دارد.                                                                  |
| تست `TestCopiesMatchPackagesConfig` خطا می‌دهد    | `pnpm sync:gamedata` را فراموش کرده‌اید.                                                                           |
| آیتم در Locker «قفل» است                          | آیتم هنوز خریداری نشده؛ پس از خرید محلی در کمد ظاهر می‌شود.                                                        |
| باشگاه‌ها دیده نمی‌شوند                           | کلید `clubTeams.enabled` خاموش است.                                                                                |
| تصویرها در کلون جدید خراب‌اند                     | `git lfs install` و بعد `git lfs pull` را بزنید.                                                                   |

## ۱۰. بخش (تب) کاملاً جدید

اضافه کردن یک **نوع** تازه به فروشگاه (مثلاً «جشن گل» یا «قاب پروفایل») کار برنامه‌نویسی است، چون هر نوع باید جایی در
بازی دیده شود: تب فروشگاه، نوع داده در `packages/config`، اعتبارسنجی سرور و نمایش در مسابقه یا پروفایل. این را به‌عنوان
یک کار جدا درخواست کنید.

## به‌روزرسانی رابط عمودی و بسته‌ها

فروشگاه فعلی ۱۷۰ آیتم دارد: ۹۱ تیم، ۳ توپ، ۶۴ آواتار و ۱۲ بسته. بسته‌ها در تب «بسته‌ها» و دو زیرتب سکه و الماس قرار می‌گیرند؛ شش گزینه در هر زیرتب. تصاویر بسته‌ها از تصاویر موجود pouch/chest/gems دوباره استفاده می‌کنند و مقدار هر بسته از grant کاتالوگ خوانده می‌شود. بستهٔ محلی پرداخت واقعی ندارد.

تیم‌ها زیرتب مستقل دارند. آواتارها بدون زیرتب و به‌صورت ترکیبی نمایش داده می‌شوند. جستجو و قفسه حذف شده‌اند. کمد فقط آیتم‌های موجودِ تیم و توپ را نشان می‌دهد و آواتار از پنجرهٔ پروفایل انتخاب می‌شود.

مالکیت محلی در `localInventory.ts` ذخیره می‌شود و به موجودی سرور تبدیل نمی‌شود. برای نام آیتم جدید، هر سه فایل ترجمه و کپی تنظیمات `server/nakama/gamedata/cosmetics.json` را به‌روز کنید. جزئیات تجربه و محدودیت‌های بررسی در `docs/ux/PORTRAIT_UI.md` است.

## چیدمان‌ها (Formation)

کاتالوگ `formations` در `packages/config/data/cosmetics.json` شامل ۲۰ چیدمان پنج‌مهره‌ای است: متعادل، الماس و دیوار رایگان‌اند و ۱۷ مورد دیگر با سکه خریداری می‌شوند. مختصات `positions` مربوط به نیمهٔ چپ زمین شبیه‌سازی است؛ پیش‌نمایش عمودی دروازهٔ خودی را پایین نشان می‌دهد. چیدمان‌های دو طرف مستقل‌اند و در شروع مجدد پس از گل حفظ می‌شوند. فیزیک و قوانین شوت تغییر نکرده‌اند.

کمد یک تب چیدمان دارد و فقط موارد در مالکیت بازیکن را نمایش می‌دهد. `formationId` انتخاب فعال را نگه می‌دارد. خرید محلی در موجودی دستگاه و خرید آنلاین از RPC `formation_purchase` انجام می‌شود. سرور قیمت را از کاتالوگ می‌خواند و کسر سکه/ثبت مالکیت را با `MultiUpdate` و کلید create-only در ledger اتمیک انجام می‌دهد. درخواست تکراری دوباره هزینه کم نمی‌کند؛ موجودی محلی مجوز استفادهٔ آنلاین نیست.

## رد حرکت مهره‌ها (Trails)

ده آیتم غیررایگان در `cosmetics.trails` تعریف شده‌اند: شتاب طلایی، موج نئون، قطبی، آتشین، کبالت، پلاسما، زمردی، دنباله‌دار، رنگین‌کمان و سرخ. هفت مورد با سکه و سه مورد با الماس خریداری می‌شوند. پیش‌فرض `trailId` خالی است و هیچ آیتمی رایگان یا از پیش در مالکیت بازیکن نیست. کمد موارد خریداری‌شده و امکان خاموش کردن افکت را نشان می‌دهد.

`trail_purchase` قیمت معتبر سرور را از کاتالوگ می‌خواند و مالکیت را همراه کسر موجودی در تراکنش اتمیک ledger ثبت می‌کند. کلاینت در بازی آنلاین فقط شناسهٔ افکت‌های تأییدشدهٔ هر دو طرف را از state sync دریافت می‌کند. خرید محلی فقط برای دادهٔ همین دستگاه است.

رد حرکت از نمونه‌های مسیر واقعی مهره در رندر ساخته می‌شود؛ طول آن متناسب با سرعت نمایشی است، سقف طول و تعداد نمونه دارد و در توقف، شروع مجدد و تصحیح جهشی موقعیت پاک می‌شود. فقط مهره‌های همان طرفِ دارای افکت را شامل می‌شود، نه توپ یا حریف بدون مالکیت. این افکت ورودی فیزیک یا قوانین و هش وضعیت را تغییر نمی‌دهد و با گزینهٔ کاهش حرکت خاموش می‌شود.

## قابلیت‌های ثابت تیم‌ها

تمام تیم‌های اصلی، ملی و باشگاهی سه ویژگی صحیح ۱ تا ۱۰ در فیلد `attributes` دارند: `force` برای سقف قدرت شوت، `time` برای مدت نوبت، و `aim` برای طول راهنمای نشانه‌گیری. ترکیب ویژگی‌های هر تیم متفاوت است؛ ارتقا یا افزایش این مقادیر با سطح بازیکن وجود ندارد. کارت تیم‌ها در فروشگاه و کمد تمام عرض را می‌گیرد و نوارهای ویژگی‌ها در تأیید خرید هم نمایش داده می‌شوند.

فرمول‌ها: سقف ضربه برابر `baseMaxImpulse × (0.7 + 0.03 × Force)`، زمان نوبت برابر `round(baseTurnMs × (0.6 + Time / 15))` و طول راهنما برابر `260 × (0.4 + Aim / 10)` پیکسل جهان بازی است. نشانه‌گیری تصادفی نمی‌شود؛ Aim فقط برد راهنما را تغییر می‌دهد. قوانین خطا/گل و فیزیک پایهٔ برخوردها ثابت‌اند. سرور قدرت مجاز و زمان تیمِ صاحب نوبت را اعمال می‌کند؛ بات نیز همان سقف قدرت تیم خود را دارد.
